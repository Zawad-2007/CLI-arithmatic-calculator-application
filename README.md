# CLI-arithmatic-calculator-application

A simple arithmatic CLI calculator application written in C

**Usage :** ./calculator [operand] [operator sign] [operand]

**NB :** The precompiled binary is compiled in a linux system and so needed to be compiled separately from source for other platforms 



**Building from source :**





```bash
git clone "https://github.com/Zawad-2007/CLI-arithmatic-calculator-application"
cd CLI-arithmatic-calculator-application/
gcc main.c arithmatics.c -o calculator
```
